JMComic 桌面版 1.5.0

启动
1. 保持整个 JMComicDesktop 文件夹完整。
2. 双击 JMComicDesktop.exe。

使用
1. 输入作品车号、JM 编号、章节编号（例如 p123）或禁漫链接。
2. 点击“查询详情”，在“作品详情”中查看标题、作者、日期、观看、点赞、评论、标签和章节列表。
3. 在“章节范围”中选择从哪一话下载到哪一话。
4. 选择保存目录和作品文件夹命名方式。
5. 一般保持“APP 接口”“跟随系统”和默认并发即可。
6. 点击“开始下载”，在“运行日志”中查看进度和结果。

浏览漫画
- 点击顶部“浏览漫画”，应用内会弹出网页窗口并打开 https://comic18j-hbd.space/。
- 弹窗支持前进、后退、刷新、地址栏、停止加载和在系统浏览器中打开。
- 找到想下载的作品后，回到主窗口输入车号、JM 编号或作品链接进行查询。
- 网页缓存和 Cookie 保存在程序目录 data\browser，不使用 AppData。
- 网页内触发的下载会弹出保存位置选择，默认建议保存到程序目录 downloads。

账号登录
- 点击“登录”，在弹出的窗口中输入账号和密码。
- 密码只用于本次登录，不会写入设置或日志。
- 勾选“保持登录”后，服务器返回的会话会加密保存到 data\session.bin。
- 优先使用 Windows DPAPI；系统不支持时使用程序目录内的 AES-GCM 密钥后备方案。
- 退出登录会同时删除 data\session.bin 和后备密钥。

程序目录
- 所有程序数据都在 JMComicDesktop.exe 所在目录，不使用 AppData。
- 设置：data\settings.json。
- 日志：data\logs。
- 登录会话：data\session.bin。
- 网页浏览缓存与 Cookie：data\browser。
- 更新下载与备份：data\updates。
- 默认下载目录：downloads（可在界面中修改）。

界面主题
- 默认“跟随系统”，Windows 深色模式会自动使用深色主题。
- 也可以在顶部手动选择“浅色主题”或“深色主题”。

作品文件夹命名
- 按车号命名：保存目录/JM车号/章节。
- 按漫画名命名：保存目录/漫画名/章节。

多话作品 ZIP
- 选择两话或更多章节时，可按当前命名方式生成一个 ZIP。
- 按车号：JM车号.zip。
- 按漫画名：漫画名.zip。
- ZIP 内直接包含“第几话 话名”文件夹，每个文件夹内是对应话的图片。
- 默认 ZIP 创建成功后删除本次产生的中间文件夹，不处理已有文件。

主要设置
- 作品接口：APP 接口通常更稳定，网页接口在部分网络下更快。
- 图片并发：同时下载的图片数，建议 8 到 16。
- 章节并发：同时处理的章节数，普通网络建议 4 到 8。
- 图片格式：保持原格式不会二次转码。
- 代理方式：跟随 Windows 代理、不使用代理或手动填写。
- 完成后操作：任务成功后自动打开保存目录。

自更新
- 在“自更新源”中填写 HTTPS 更新清单地址或本地 JSON 文件路径。
- 可勾选“启动后自动检查”，也可以随时点击“检查更新”。
- 更新包必须通过清单中的 SHA-256 校验，且不得包含 data 或 downloads。
- 更新器会等待主程序退出，备份当前程序文件，替换后再重启。
- 替换失败会回滚；data、downloads 和加密登录会话不会被覆盖。

更新清单示例
{
  "version": "1.4.1",
  "url": "https://example.com/JMComicDesktop-1.4.1-win64.zip",
  "sha256": "更新包的64位SHA256小写十六进制值",
  "size": 12345678,
  "notes": "本次更新说明"
}
