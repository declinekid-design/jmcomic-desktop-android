# 架构说明

## 总体结构

本项目由两个独立客户端组成：

```text
JMComic-Crawler-Python
        │
        ├─ Windows desktop
        │  ├─ PySide6 UI
        │  ├─ 上游 jmcomic API/下载器
        │  ├─ 章节范围与 ZIP 插件
        │  ├─ 会话加密
        │  ├─ Qt WebEngine 浏览器
        │  └─ 独立更新器
        │
        └─ Android application
           ├─ MainActivity 原生界面
           ├─ Chaquopy Python 3.12
           ├─ 上游 jmcomic API/下载器
           ├─ 章节范围与 ZIP 插件
           ├─ AES-GCM 会话
           ├─ BrowserActivity 站内浏览
           └─ 系统 APK 安装器自更新
```

Windows 端和 Android 端不共享运行进程，但复用同一上游 Python 包的查询、
下载器和 ZIP 插件逻辑。

## Windows 启动流程

`desktop/jmcomic_desktop.py` 是入口文件，调用
`desktop/jmdesktop/app.py`：

1. 创建 `QApplication`，设置 Fusion 样式和中文字体。
2. 应用系统主题。
3. 导入上游 `jmcomic`，失败时写入 `data/startup-error.log`。
4. 通过 `--self-test`、`--smoke-test` 或 `--browser-smoke-test` 运行验证模式。
5. 正常模式创建 `JMComicDesktopWindow`。

## 桌面 UI 与业务流

主窗口由 `window.py` 协调：

```text
输入车号/链接
    -> _parse_jm_input()
    -> 后台查询线程
    -> album 详情
    -> details.py 生成详情文本
    -> 填充章节起止下拉框
    -> _build_option()
    -> DesktopDownloader
    -> 进度/章节/导出事件
    -> 图片目录或 ZIP
```

界面层只负责收集设置和显示事件。查询和下载在后台线程执行，通过
`queue.Queue` 把事件送回 Qt 主线程，避免下载时冻结界面。

## 下载与打包

`downloader.py` 继承上游 `JmDownloader`，增加：

- `photo_range`：保存用户选择的章节区间。
- `do_filter()`：在专辑下载前过滤章节。
- `before_album()`、`before_photo()`、`after_image()`：发送章节和图片进度。
- `record_export_filepath()`：把上游插件生成的 ZIP 路径报告给界面。

命名规则由 `constants.py` 提供：

```text
按车号：目录 Bd / Ajm_id / Pindextitle，ZIP JM{Aid}
按漫画名：目录 Bd / Atitle / Pindextitle，ZIP {Atitle}
```

ZIP 列表由上游插件在 `after_album` 阶段生成，图片保存逻辑继续由
[hect0x7/JMComic-Crawler-Python](https://github.com/hect0x7/JMComic-Crawler-Python)
提供。

## 配置与会话

`constants.py` 计算运行目录：

- 打包后：`JMComicDesktop.exe` 所在目录。
- 源码运行：仓库中的 `desktop` 目录。
- 测试或特殊部署：可以通过环境变量覆盖运行目录。

运行时数据：

```text
data/settings.json   界面和下载设置
data/session.bin     加密后的会话
data/session.key     AES-GCM 后备密钥，仅在非 DPAPI 路径使用
data/browser/        浏览器缓存和 Cookie
data/logs/           应用和更新器日志
data/updates/        更新包、暂存和备份
downloads/           默认下载目录
```

`session.py` 使用带固定熵的 Windows DPAPI。DPAPI 不可用时，使用
AES-GCM 和程序目录内生成的 32 字节随机密钥。密码不会写入会话文件。

## 内置浏览器

`browser.py` 使用 Qt WebEngine：

- 默认地址为 `https://comic18j-hbd.space/`。
- 工具栏提供前进、后退、刷新、停止、地址输入和系统浏览器打开。
- Profile 数据位于程序目录，不使用 `%APPDATA%`。
- 网页下载会弹出保存路径，默认指向程序目录下的 `downloads`。

## 自更新

自更新分成两个进程：

1. 主程序中的 `update_manager.py` 读取清单、下载更新包并校验 SHA-256。
2. 独立 `JMComicDesktopUpdater.exe` 等待主程序退出，验证 ZIP，备份旧程序，
   替换文件并重启主程序。

更新器只允许更新程序目录中的非用户文件。以下内容始终保留：

```text
data/
downloads/
updater/
预览图/
更新文件/
```

## Android 结构

### MainActivity

- 创建原生作品查询、设置、章节范围、进度和日志界面。
- 通过 Chaquopy 调用 `app/python/jmcomic_service.py`。
- 展示完整详情，并提供开始话、结束话和“全部章节”选择。
- 支持账户密码登录、会话状态、自更新检查和 APK 下载。
- 主题由 `ThemeUtil` 程序化应用，支持浅色、深色和跟随系统。

### Python service

`jmcomic_service.py` 是 Android 业务核心：

- `initialize`：创建应用目录、加载加密会话并导入 `jmcomic`。
- `query_album`：解析输入并返回详情与章节数组。
- `start_download`：按 `start_index`、`end_index` 过滤章节。
- 多话时启用上游 ZIP 插件；目录规则为
  `Bd / Ajm_id / Pindextitle` 或 `Bd / Atitle / Pindextitle`。
- ZIP 名称为 `JM{Aid}` 或 `{Atitle}`，内部保留章节文件夹相对路径。
- `login`、`logout`：调用上游客户端并保存 AES-GCM 加密会话。
- `check_update`：读取 HTTPS 清单、下载 APK 并校验 SHA-256。

Android Python 与 Chaquopy 适配层位于 `app/python/curl_cffi/`，用于兼容
`jmcomic` 的导入路径，不包含本地账号或站点凭据。

### BrowserActivity

- 打开 `https://comic18j-hbd.space/`，支持返回、首页、刷新和页面缩放。
- 接受 Cookie、第三方 Cookie 和 DOM 存储，保持网页登录状态。
- 网页下载交给 Android DownloadManager，并传递 Cookie、User-Agent 和
  Referer。
- 网页文件选择器连接 Android 系统文件选择界面。

### DownloadsActivity

- 递归扫描应用下载目录中的 ZIP、图片和 APK。
- 显示文件时间、大小和完整路径。
- 通过 FileProvider 将文件安全交给系统应用打开。

### 数据目录与权限

```text
应用私有目录/
├─ files/jmcomic/
│  ├─ settings.json
│  ├─ session.bin
│  ├─ session.key
│  ├─ download-history.json
│  ├─ logs/
│  └─ updates/
└─ external-files/Downloads/JMComic/
```

Android 版不读取或写入 `%APPDATA%`。自更新需要 `REQUEST_INSTALL_PACKAGES`
权限，但下载的 APK 仍必须由系统安装器确认；应用不会静默安装。

## 验证策略

Windows：

```powershell
python .\desktop\jmcomic_desktop.py --self-test
python .\desktop\jmcomic_desktop.py --smoke-test
python .\desktop\jmcomic_desktop.py --browser-smoke-test
python .\desktop\updater_app.py --self-test
```

Android：

```powershell
.\android\scripts\build_apk.ps1 `
  -ToolchainRoot $env:ANDROID_TOOLCHAIN_ROOT `
  -BuildPython $env:CHAQUOPY_BUILD_PYTHON
```

Android 脚本执行 Gradle `assembleDebug`、`lintDebug` 和
`apksigner verify`，构建成功后会输出 APK 路径、大小和 SHA-256。发布前还应
检查 APK 包名、版本号、minSdk、targetSdk、双架构和权限。

## 安全边界

- 不把账号密码写入设置、日志或 Git。
- 不把本地会话文件复制到仓库。
- 更新包必须通过哈希校验和路径安全检查。
- 仓库不保存用户下载内容。
- 网络请求由用户主动触发的查询、下载、登录或更新产生。
