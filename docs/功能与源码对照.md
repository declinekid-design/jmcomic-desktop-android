# 功能与源码对照

本文把用户可见功能和仓库中的主要实现文件对应起来，便于查看每次功能变更的
落点、验证方式和相关 Release 附件。

## Windows 桌面端 1.5.0

| 功能 | 用户可见行为 | 主要源码 | 验证点 |
| --- | --- | --- | --- |
| 多种作品输入 | 支持车号、JM 编号、章节号 `p123456` 和作品链接 | `desktop/jmdesktop/window.py` | `_parse_jm_input` 单元路径和桌面自检 |
| 作品详情 | 显示标题、ID、链接、作者、日期、页数、观看、点赞、评论、标签、人物和作品 | `desktop/jmdesktop/details.py`、`window.py` | `--self-test` 的作品详情格式检查 |
| 章节列表 | 显示章节总数、话名和 ID，允许选择章节范围 | `desktop/jmdesktop/window.py` | 章节下拉框数量和默认范围自检 |
| 范围下载 | 只下载选中的开始章节到结束章节 | `desktop/jmdesktop/downloader.py`、`window.py` | `chapter_filter` 和进度事件检查 |
| 车号命名 | 作品目录使用 `JM车号`，ZIP 使用 `JM{Aid}` | `desktop/jmdesktop/constants.py`、`window.py` | `id_dir_rule`、`id_zip_rule` 自检 |
| 漫画名命名 | 作品目录和 ZIP 使用漫画标题 | `desktop/jmdesktop/constants.py`、`window.py` | `title_dir_rule`、`title_zip_rule` 自检 |
| ZIP 分话结构 | ZIP 内以“第几话 话名”建立文件夹 | `desktop/jmdesktop/window.py`、上游 `jmcomic` ZIP 插件 | 打包路径和生成文件自检 |
| 图片格式 | 保留原格式或输出 JPG、PNG、WEBP | `desktop/jmdesktop/constants.py`、`window.py` | 选项构建和实际下载流程 |
| 并发控制 | 调整图片并发数和章节并发数 | `desktop/jmdesktop/window.py`、`downloader.py` | 选项构建和下载任务 |
| 代理设置 | 跟随系统、不使用代理或手动输入 | `desktop/jmdesktop/constants.py`、`window.py` | 设置保存和选项构建 |
| 主题切换 | 浅色、深色、跟随系统 | `desktop/jmdesktop/theme.py`、`constants.py`、`app.py` | `dark_theme_applies`、`light_theme_applies` 自检 |
| 账号登录 | 账号密码登录，可选择保持登录 | `desktop/jmdesktop/login.py`、`session.py`、`window.py` | 登录控件和会话加密往返自检 |
| 会话加密 | DPAPI 优先，AES-GCM 后备 | `desktop/jmdesktop/session.py` | `session_encryption` 自检，退出登录清理会话 |
| 内置浏览器 | 打开 `https://comic18j-hbd.space/`，支持导航和下载 | `desktop/jmdesktop/browser.py`、`app.py` | `--browser-smoke-test` |
| 便携数据目录 | 设置、日志、Cookie、更新和下载数据位于程序目录 | `desktop/jmdesktop/constants.py`、`settings.py` | `portable_data_dir` 自检 |
| 自更新 | 检查 HTTPS/本地清单、下载、校验、替换和回滚 | `desktop/jmdesktop/update_manager.py`、`desktop/updater_app.py` | 主程序自检与 `updater_app.py --self-test` |
| 更新保护 | 不覆盖 `data`、`downloads`、`updater`、预览图和更新文件 | `desktop/updater_app.py` | 更新器自检中的保留目录检查 |

## Android 浏览版 1.0.0

| 功能 | 用户可见行为 | 主要源码 | 验证点 |
| --- | --- | --- | --- |
| WebView 浏览 | 默认打开 `https://comic18j-hbd.space/` | `android/app/java/com/local/comicreader/MainActivity.java` | APK 启动和 DEX 字符串检查 |
| 网页登录保持 | 接受 Cookie、第三方 Cookie、DOM 存储和数据库 | `MainActivity.java` | `configureCookies`、`configureWebView` |
| 返回和刷新 | 工具栏提供返回上一页和页面刷新 | `MainActivity.java` | `navigateBack`、`webView.reload()` |
| 系统下载 | 使用 DownloadManager 下载网页文件 | `MainActivity.java` | 下载请求、Cookie、Referer、UA 处理 |
| 下载记录 | 查看下载状态、进度和大小 | `DownloadsActivity.java` | 下载列表查询和状态渲染 |
| 图片阅读 | 在当前下载图片之间上一页、下一页 | `ReaderActivity.java` | Bitmap 采样、预览和页码切换 |
| 文件选择 | 网页上传入口连接 Android 文件选择器 | `MainActivity.java` | `onShowFileChooser` 和 `onActivityResult` |
| Android 8+ | minSdk 26、targetSdk 35 | `AndroidManifest.xml`、`build_apk.ps1` | `aapt` 和 `apksigner` 构建输出 |

## 构建与发布文件

| 文件 | 作用 |
| --- | --- |
| `desktop/build.ps1` | 创建虚拟环境、安装依赖、打包桌面端和更新器 |
| `desktop/JMComicDesktop.spec` | PyInstaller Windows 打包配置 |
| `desktop/make_update_package.ps1` | 生成自更新 ZIP 和校验清单 |
| `android/scripts/build_apk.ps1` | 编译 Java、资源、DEX、签名并验证 APK |
| `CHANGELOG.md` | 每次功能变更的版本记录 |
| `docs/架构说明.md` | 组件结构、数据流和存储边界 |
| `docs/发布与下载.md` | 版本号、附件、哈希和发布步骤 |

## 版本文件范围

仓库当前只保留最新正式版本对应的源码和构建文件。Android 1.0.0 与
Windows 1.5.0 属于同一交付批次，因此一并保留。1.4.0 和更早版本只在
`CHANGELOG.md` 记录功能增加、修复和兼容性变化，不再保留旧构建附件。
