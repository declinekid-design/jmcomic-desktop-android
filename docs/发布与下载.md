# 发布与下载

## 下载入口

公开下载入口：

[GitHub Releases](https://github.com/declinekid-design/jmcomic-desktop-android/releases)

每个 Release 应同时包含源码提交说明、可安装产物、校验值和升级说明。
Windows 和 Android 产物使用不同文件名，避免平台混淆。

## 版本号

桌面端和 Android 端分别维护版本号：

```text
Windows: JMComic Desktop 1.5.0
Android: JMComic Android 1.0.0
```

同一个版本线使用 `v主版本.次版本.修订版本` 标签；跨平台同时发布时可以附加
平台后缀。例如当前标签：

```text
v1.5.0-android-1.0.0
```

修复版发布应增加修订号，例如 `v1.5.1-android-1.0.1`。不要把未完成构建的
草稿附件作为正式下载。

## Windows 构建

```powershell
cd desktop
.\build.ps1
```

产物：

```text
dist/JMComicDesktop/
dist/JMComicDesktopUpdater/
```

将 `dist/JMComicDesktopUpdater` 复制为
`dist/JMComicDesktop/updater`，再把整个 `JMComicDesktop` 目录压缩。
发布前运行：

```powershell
.\dist\JMComicDesktop\JMComicDesktop.exe --self-test
.\dist\JMComicDesktop\JMComicDesktop.exe --smoke-test
.\dist\JMComicDesktop\updater\JMComicDesktopUpdater.exe --self-test
```

## Android 构建

```powershell
$env:ANDROID_TOOLCHAIN_ROOT = 'C:\path\to\android-toolchain'
$env:CHAQUOPY_BUILD_PYTHON = 'C:\path\to\python.exe'

.\android\scripts\build_apk.ps1 `
  -ToolchainRoot $env:ANDROID_TOOLCHAIN_ROOT `
  -BuildPython $env:CHAQUOPY_BUILD_PYTHON `
  -OutputApk .\artifacts\JMComic-Android-1.0.0.apk
```

脚本会执行：

1. Gradle `assembleDebug` 构建 Java、资源、DEX、Chaquopy 和双架构原生库。
2. Gradle `lintDebug` 检查 Android 8 和 targetSdk 兼容问题。
3. 复制最终 APK。
4. `apksigner verify` 验证签名。
5. 输出文件大小和 SHA-256。

Chaquopy 在首次构建时会下载 Python 3.12 Android Wheels。`jmcomic 2.7.7`
使用独立 `--no-deps` 安装，避免 Android 仓库缺少 `curl-cffi` 导致构建失败。
发布后的 APK 应记录 SHA-256；当前 APK 使用固定调试证书，不是 Play Store
正式发布证书。

## 更新清单

Windows 和 Android 自动更新都使用 JSON 清单：

```json
{
  "version": "1.5.1",
  "url": "https://example.com/JMComicDesktop-1.5.1-win64.zip",
  "sha256": "64位小写SHA256十六进制值",
  "size": 12345678,
  "notes": "修复内容与使用说明"
}
```

清单和更新包可以使用 HTTPS，也可以在本地路径模式下测试。发布前必须实际
计算 SHA-256，并确认更新包不包含 `data`、`downloads`、`updater`。

Android 更新清单保存在
[`android/update-manifest.json`](../android/update-manifest.json)。当前版本为
`1.0.0`；以后发布时必须同时增加 `version`，更新下载 URL、`sha256` 和 `size`
到新 APK 的实际值。

## 旧版本文件

仓库只保留最新正式版本的源码、构建脚本和下载附件。旧版本不再上传对应的
源码包、安装包或压缩包，只在 `CHANGELOG.md` 中记录功能增加、修复和兼容性
变化。当前保留范围是 Windows 1.5.0 和 Android 完整下载器 1.0.0。

Release 页面中的旧附件 `JMComicBrowser-1.0.0-debug.apk` 已删除，并由
`JMComic-Android-1.0.0.apk` 替代。这样同一版本下不会同时出现 WebView 壳和
完整下载器两个 Android 包。

## 公开仓库检查

公开前确认：

1. README、CHANGELOG、CREDITS 和 LICENSE 已更新。
2. Release 不是草稿，附件状态为 `uploaded`。
3. 附件大小和 SHA-256 与本地一致。
4. Android Release 中不保留旧 WebView APK。
5. 仓库没有 `.env`、令牌、Cookie、会话、下载图片或个人信息。
6. 上游项目和第三方依赖的许可证已保留。

仓库公开后，访问者可以直接浏览源码，也可以从 Releases 页面下载 Windows
便携包和 Android APK。
